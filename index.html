Meldingen

Echte meldingen op je telefoon via ntfy, een gratis dienst. De tekst van een melding (bijv. de titel van een notitie) gaat via de server van ntfy.sh.

  1. Installeer de app ntfy (Play Store).
  2. Tik in ntfy op + en vul dit onderwerp in.
  3. Tik hieronder op "Stuur testmelding".

Meldingen worden maximaal 3 dagen vooruit ingepland, telkens als je de app opent. Open de app dus minstens elke paar dagen. Een melding die je later wijzigt, kan nog één keer met de oude tekst komen.
