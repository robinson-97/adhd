# Overzicht

Simpele app tegen de chaos: werkagenda met uren per maand + uitgavenboekje met categorieën en maandoverzicht.

- Open `index.html` in de browser (of host de map, bv. GitHub Pages) en kies "Zet op beginscherm" om hem als app te gebruiken.
- Alle gegevens staan alleen op je eigen apparaat (localStorage). Gebruik **Exporteer/Importeer** onderaan Uitgaven voor een back-up.
